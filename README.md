## 🗂️ About

A comprehensive collection of 589,000+ icons spanning color PNGs, monochrome SVG sets, macOS ICNS assets, animated SVG spinners, Meteocons weather animations, Apple SF Symbols, heavy metal band logos, music emblem rings, and 226 icon set collections via the Iconify API submodule. Includes native macOS desktop apps and specialized CLI/TUI utilities like **`ringicon`** for creating album art ring icons.

## 🎵 Music Collection & RingIcon Tool (`color/music/`)

The repository includes a dedicated music iconography section with 320+ heavy metal band logos, 150+ music emblem rings, and a custom **`ringicon`** production tool for creating album-art ring icons.

### 1. Music Collections (`color/music/`)

- **Band Logos (`color/music/band-logos/png/`)**: 320+ transparent high-resolution PNG logos for heavy metal & rock bands (Metallica, Megadeth, Slayer, Anthrax, Aerosmith, DMX, Saxon, Mortician, Marduk, Destruction, etc.).
- **Music Rings (`color/music/rings/`)**: 150+ emblem & circular album rings for audio players & desktop launchers (`deathrashed.png`, `schizophrenia.png`, `electrified.png`, `brainsatched.png`, `attomica.png`).

### 2. RingIcon Production CLI & TUI Application (`color/music/rings/Tool/GPT/`)

`ringicon` is a custom high-performance application built to eliminate repetitive manual workflows (e.g. Canva) for cropping album artwork into circles and layering multi-colored ring borders:

```text
Source Image / URL → Position & Crop → Ring Layer Stack → Transparent PNG
```

#### Running the Interactive TUI

```bash
cd /Volumes/Apfspace/Icons/color/music/rings/Tool/GPT
./ringicon
```

The interactive TUI dashboard features:
- **Keyboard navigation**: Arrow keys to pan/position, `+`/`-` to zoom, `I` to load image/URL, `P` for presets, `R` to customize ring stack, `V` for real PNG render/preview, `Enter` to export.
- **Visual Ring Stack Builder**: Configure inner/outer ring widths, transparent gaps, custom hex/RGB colors, and opacity.

#### CLI Commands & Automation

```bash
# Single image with preset
./ringicon make cover.jpg --preset black-green-black --zoom 1.25 --x -40 --y 20 --out output.png

# Custom multi-ring stack (inner to outer)
./ringicon make cover.jpg --rings "black:8,green:24,black:8" --size 1000 --out output.png

# Advanced ring syntax with transparent gaps and opacity
./ringicon make cover.jpg --rings "#111111:10,#f7931e:32:4:0.95" --out output.png

# Process image directly from HTTP URL
./ringicon make "https://example.com/cover.jpg" --preset single-orange --out ring.png

# Batch process directory of covers
./ringicon batch ./covers --preset single-orange --out ./rings --rename-existing
```

#### Finder & System Integration
- **`scripts/finder-ringicon.sh`**: Integrated script for macOS Finder / Automator to generate ring icons directly from right-clicking image files.
- **`completions/ringicon.zsh`**: Full Zsh shell completion for all flags & presets.
- **Go Engine Variant (`ringicon-go/`)**: High-speed compiled Go binary for automated server pipelines.

### Applying macOS Folder Icons

```bash
# Using fileicon (brew install fileicon)
fileicon set ~/Projects/MyApp ./macos/folders/misc/github.icns

# Using included script
./utilities/scripts/apply-icon.sh github.icns ~/Projects/MyApp

# Or via Finder
# 1. Get Info on icon file (⌘ + I)
# 2. Click icon preview → Copy (⌘ + C)
# 3. Get Info on target folder
# 4. Click folder icon → Paste (⌘ + V)
```

### Applying App Icons

```bash
# Replace app icon
fileicon set /Applications/MyApp.app ./macos/apps/icns/custom-icon.icns

# Using included script
./utilities/scripts/apply-icon.sh custom-icon.icns /Applications/MyApp.app

# Refresh icon cache
sudo killall Finder && sudo killall Dock
```
