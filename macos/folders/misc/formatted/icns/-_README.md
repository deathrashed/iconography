# Icon Naming Reference

## Prefix Guide

| Prefix | Category | Notes |
|--------|----------|-------|
| `-` | Misc | Catchall/uncategorized |
| `ai-` | AI | ChatGPT, Claude, Gemini |
| `app-` | Apps | Application icons |
| `apple-` | Apple | Apple branding, appstore |
| `browser-` | Browsers | Arc, Chrome, Firefox, etc. |
| `cloud-` | Cloud | pCloud, OneDrive, Syncthing |
| `dev-` | Dev | Languages, frameworks, tools |
| `ext-` | Ext | File extension icons |
| `file-` | File | Generic file type icons |
| `fun-` | Fun | Memes, games, novelty |
| `media-` | Media | Images, video, audio generic |
| `music-` | Music | Bands, albums, genres |
| `os-` | OS | Linux, Microsoft/Windows |
| `sys-` | Sys | System folders, wallpapers (wp-) |

## Naming Rules

- `-` prefix for misc (sorts to top in Finder)
- Descriptors kept when useful: `linux-`, `microsoft-`, `wp-`, `appstore-`
- Alt variants: `-alt` suffix
- Fill style: `-fill` suffix
- Color variants: `-dark`, `-light`, `-gradient`

## Examples
