## 🔍 Finding Symbols

```bash
# Browse a category
open symbols/sf-symbols-light/media/

# Search within a category
ls symbols/sf-symbols-light/arrows/ | grep up

# Search all symbols
find symbols/sf-symbols-light -name "*star*"
```
